 *  facility list (ARCHITECTURE.md Anti-Pattern 1). `recAreaId` is the explicit
 *  override for a bad name auto-match (D-02); it skips the /recareas name search

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-08 | Denial of Service | `AreaWatchSchema.areas` | mitigate | `.min(1)` rejects an empty area list that would produce a silently no-op watch; combined with the 20-facility cap in plan 04-05, an `areas` array's length cannot inflate the polled facility count past `AREA_FACILITY_CAP` regardless of how many areas are listed |
| T-04-09 | Tampering | `AreaWatchSchema.areas[].recAreaId` | mitigate | `z.number().int().positive()` rejects strings, negatives, floats, and `NaN` before the value is ever interpolated into a RIDB URL path segment — this is the first of two defenses (the second is `encodeURIComponent` at the call site in plan 04-03) |
| T-04-10 | Tampering | `WatchSchema` preprocess step | mitigate | The preprocess guard checks `typeof val === 'object' && !Array.isArray(val) && val !== null` before spreading, so a hostile array or primitive falls through to the discriminated union and is rejected rather than being coerced into a synthetic `facility` object |
| T-04-11 | Denial of Service | Migration of live `watches.json` | mitigate | The no-`type` -> `facility` preprocess is asserted by a dedicated test case; without it, the production poller's next run would hard-fail config load on every existing watch |
