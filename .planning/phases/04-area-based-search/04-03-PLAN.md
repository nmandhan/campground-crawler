**2. `resolveArea`** — a line-for-line structural mirror of `resolveFacility`:

```typescript
export async function resolveArea(areaName: string, opts?: ClientOptions): Promise<ResolvedRecArea> {
  const url = new URL(`${RIDB_BASE}/recareas`);
  url.searchParams.set('query', areaName);
  url.searchParams.set('limit', '10');

  const headers: Record<string, string> = {};
  if (opts?.ridbApiKey) {
    headers['apikey'] = opts.ridbApiKey;
  }

  const raw = await retryWithBackoff(
    () => fetchJson(url.toString(), { headers, fetchImpl: opts?.fetchImpl }),
    { sleep: opts?.sleep }
  );

  const parsed = RidbRecAreaSearchSchema.safeParse(raw);
  if (!parsed.success) {
    throw new ResponseSchemaError(
      'RIDB recreation area search returned an unexpected shape',
      formatZodIssues(parsed.error.issues)
    );
  }

  const [first, ...rest] = parsed.data.RECDATA;
  if (!first) {
    throw new RecAreaNotFoundError(`no RIDB recreation area matched "${areaName}"`, areaName);
  }

  return {
    recAreaId: first.RecAreaID,
    recAreaName: first.RecAreaName,
    alternatives: rest.map((r) => r.RecAreaName),
  };
}
```

Do NOT set `sort=Name` here (unlike `resolveFacility`) — D-09's "keep RIDB's returned order"
applies to relevance ranking for the top-match pick.

**3. A module-private classifier**, so filtering and tagging can never disagree:

```typescript
function classifyFacility(f: { FacilityID: number; FacilityName: string; FacilityTypeDescription?: string; Reservable?: boolean }): AreaFacility | null {
  const desc = f.FacilityTypeDescription;
  if (desc === undefined) return null;          // needs hydration, caller decides
  if (!CAMPGROUND_TYPE_PATTERN.test(desc)) return null;
  if (f.Reservable !== true) return null;       // strict: undefined is NOT reservable (fail closed)
  return {
    facilityId: f.FacilityID,
    facilityName: f.FacilityName,
    facilityType: GROUP_TYPE_PATTERN.test(desc) ? 'group' : 'standard',
  };
}
```

**4. A module-private hydration helper** for the compact-stub case:

```typescript
async function hydrateFacility(facilityId: number, opts?: ClientOptions): Promise<AreaFacility | null> {
  const url = new URL(`${RIDB_BASE}/facilities/${encodeURIComponent(String(facilityId))}`);
  const headers: Record<string, string> = {};
  if (opts?.ridbApiKey) headers['apikey'] = opts.ridbApiKey;

  const raw = await retryWithBackoff(
    () => fetchJson(url.toString(), { headers, fetchImpl: opts?.fetchImpl }),
    { sleep: opts?.sleep }
  );
  // /facilities/{id} returns the bare record, not the RECDATA envelope. Accept either.
  const envelope = RidbFacilitySearchSchema.safeParse(raw);
  const record = envelope.success ? envelope.data.RECDATA[0] : RidbFacilitySchema.safeParse(raw).data;
  if (!record) return null;
  return classifyFacility(record);
}
```

**5. `listAreaFacilities`**:

```typescript
export async function listAreaFacilities(recAreaId: number, opts?: ClientOptions): Promise<AreaFacility[]> {
  const url = new URL(`${RIDB_BASE}/recareas/${encodeURIComponent(String(recAreaId))}/facilities`);
  url.searchParams.set('limit', '50');

  const headers: Record<string, string> = {};
  if (opts?.ridbApiKey) headers['apikey'] = opts.ridbApiKey;

  const raw = await retryWithBackoff(
    () => fetchJson(url.toString(), { headers, fetchImpl: opts?.fetchImpl }),
    { sleep: opts?.sleep }
  );

  const parsed = RidbRecAreaFacilitiesSchema.safeParse(raw);
  if (!parsed.success) {
    throw new ResponseSchemaError(
      'RIDB recreation area facilities returned an unexpected shape',
      formatZodIssues(parsed.error.issues)
    );
  }

  const out: AreaFacility[] = [];
  let hydrations = 0;
  for (const f of parsed.data.RECDATA) {           // D-09: RIDB's order, never re-sorted
    const direct = classifyFacility(f);
    if (direct) { out.push(direct); continue; }
    if (f.FacilityTypeDescription !== undefined) continue;  // typed, but not a reservable campground
    if (hydrations >= AREA_HYDRATION_LIMIT) continue;       // T-04-02 bound
    hydrations += 1;
    try {
      const hydrated = await hydrateFacility(f.FacilityID, opts);
      if (hydrated) out.push(hydrated);
    } catch {
      // One un-hydratable facility never fails the whole area (project convention:
      // a per-unit failure is isolated, never aborts its siblings).
    }
  }
  return out;
}
```

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| RIDB API -> poller | Untrusted third-party JSON, unbounded in size and arbitrary in shape |
| `watches.json` `recAreaId` -> RIDB URL path | Developer-authored integer interpolated into a request path |
| Error messages -> `runs.json` in a PUBLIC repo | `RIDB_API_KEY` must never reach a committed file |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-01 | Tampering | `resolveArea` / `listAreaFacilities` response handling | mitigate | `RidbRecAreaSearchSchema.safeParse` / `RidbRecAreaFacilitiesSchema.safeParse` run before ANY field access; a failed parse throws `ResponseSchemaError` carrying only zod issue paths, never the response body |
| T-04-02 | Denial of Service | `listAreaFacilities` hydration loop | mitigate | `AREA_HYDRATION_LIMIT = 40` hard-caps per-facility `GET /facilities/{id}` calls per area, so a RecArea containing 500 facilities cannot turn one watch into 500 RIDB requests and blow the 50 req/min budget. Asserted by a test that feeds 100 stub entries and counts requests |
| T-04-03 | Information Disclosure | RIDB auth on all three new calls | mitigate | The key is set only as the `apikey` header; every URL is built with `new URL` + `searchParams`, so the key can never land in `HttpError.url` (which `describeFailure` renders into `runs.json` in a public repo). Asserted by a test recording fetched URLs and by a zero-match grep for `searchParams.set('apikey'` |
| T-04-04 | Tampering | `resolveArea` query construction | mitigate | Area name goes through `url.searchParams.set('query', areaName)`, percent-encoded by `URLSearchParams` — no string concatenation |
| T-04-05 | Tampering | `recAreaId` / `facilityId` path segments | mitigate | Defense in depth: `AreaWatchSchema` (plan 04-02) rejects non-positive-integer `recAreaId` at config load, and `encodeURIComponent(String(id))` neutralizes any `../` even if a caller bypasses the schema |
| T-04-06 | Denial of Service | Per-facility hydration failure | mitigate | The hydration `try/catch` isolates one failing facility so it cannot abort resolution of its siblings — the project's established per-unit isolation convention |
| T-04-12 | Spoofing | Trusting RIDB's top search result | accept | D-02/D-03 explicitly lock auto-pick-top-match with an `alternatives` list and a `recAreaId` override as the escape hatch, matching how `resolveFacility` already behaves. Inventing a different trust model here is out of scope |
</threat_model>
