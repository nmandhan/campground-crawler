Requirements, all of them load-bearing:
- `formatRelativeTime(iso: string, now: Date): string`. `now` is an **explicit parameter, not
  `new Date()` read inside the function** — this keeps the function pure and the tests
  deterministic, and it is what lets `page.tsx` render a single consistent "as of" moment.
  Implement with `new Intl.RelativeTimeFormat('en', { numeric: 'auto' })` and a descending
  threshold ladder: year (31536000s), month (2592000s), week (604800s), day (86400s),
  hour (3600s), minute (60s), second. Pick the largest unit whose absolute value is ≥ 1, and
  round toward zero. Guard: if `Number.isNaN(Date.parse(iso))`, return `'unknown'`.
  With `numeric: 'auto'`, verify in the tests that a 30-second delta renders `'30 seconds ago'`
  and not `'now'`; if the runtime's `'auto'` mode collapses small values, switch to
  `{ numeric: 'always' }` — the tests in `<behavior>` are the contract, not the option value.
- `formatAbsolute(iso: string): string` — `Intl.DateTimeFormat('en-US', { dateStyle: 'medium',
  timeStyle: 'short', timeZone: 'UTC' })` plus a ` UTC` suffix. Pinning the time zone matters:
  the string is rendered on a Vercel server and must not silently vary with the server's locale.
  Returns `'unknown'` for an unparseable input.
- `formatDateRange(start: string, end: string): string` for `YYYY-MM-DD` inputs where `end` is
  the **exclusive checkout date** (see the `Watch.dateRange` docstring in `src/types.ts`).
  Nights = whole days between `start` and `end`. Output `'Oct 9 – Oct 11, 2026 (2 nights)'`
  (en-dash U+2013, `(1 night)` singular). If the two dates fall in different calendar years,
  render the year on both sides. Returns `'unknown dates'` on unparseable input or when
  `end <= start`. Parse with `Date.UTC` from the split components, never `new Date('YYYY-MM-DD')`
  interpreted in local time, so nothing shifts by a day on a non-UTC server.
