```typescript
import type { Watch } from './types';

/** The single place a Watch becomes display text. A FacilityWatch shows its parkName;
 *  an AreaWatch shows its area names joined by ' + ' with an '(area)' suffix so the two
 *  kinds of watch are never confusable in the UI (AREA-01). */
export function watchLabel(watch: Watch): string {
  if (watch.type === 'area') {
    const names = watch.areas.map((a) => a.name).filter((n) => n.length > 0);
    if (names.length === 0) return '(area, none listed)';
    return `${names.join(' + ')} (area)`;
  }
  return watch.parkName;
}
```

```typescript
function findMatchedSlot(
```

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| `watches.json` / `runs.json` / `state.json` (fetched from a PUBLIC GitHub repo) -> dashboard render | Untrusted-at-render-time JSON; a malformed or hostile entry must degrade one row, never crash the page or emit an attacker-controlled link |
| Poller type declarations -> hand-copied dashboard declarations | Silent drift is the failure mode; there is no compiler link between the two projects |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-13 | Denial of Service | `MatchedSlotSchema` / `parseRunLog` | mitigate | `facilityType` is added with `.default('standard')`, so every `runs.json` entry written before this phase still parses. Without the default, `parseRunLog` would skip every historical entry and blank the entire timeline — the dashboard is currently the only working notification surface |
| T-04-14 | Tampering | `watchLabel` output | mitigate | Area names are rendered as React text children (auto-escaped by React), never via `dangerouslySetInnerHTML`; `watchLabel` returns a plain string and no task in this plan introduces raw HTML |
| T-04-15 | Spoofing | Booking links on match rows | mitigate | `safeBookingUrl`'s `https://www.recreation.gov/` prefix check (trailing slash included, which is what rejects `https://www.recreation.gov.evil.com/`) and the `CAMPSITE_ID_ALLOWLIST` regex are preserved verbatim; acceptance criteria grep for both. This plan changes only the row's display name, never its URL construction |
| T-04-16 | Repudiation | Group vs standard campground confusion | mitigate | D-05: a group campground match renders as `<name> [GROUP]`. The user's actual use case is 1-2 tent sites; an unflagged group match would send them to book a site they cannot use |
| T-04-17 | Tampering | Hand-mirrored type drift | mitigate | The `_assert*` compile-time drift-check line is preserved per schema, and `cd dashboard && npx tsc --noEmit` is an acceptance criterion, so a mirrored schema that disagrees with its mirrored interface fails the build |
</threat_model>
